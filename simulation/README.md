# Simulation files

Place Verilog testbenches and simulation notes in this folder.

Suggested testbenches:
- VGA counter/sync/active-video tests.
- Renderer coordinate tests.
- Button synchronizer/debounce tests.
- Paddle movement and boundary tests.
- Ball wall/paddle collision tests.
- Score and round-reset tests.
- Game-controller state-transition tests.

Each module owner should record:
- What behavior was tested.
- The expected result.
- The actual result.
- Any known failure or limitation.

A screenshot can support the result, but keep the testbench source in this folder.
